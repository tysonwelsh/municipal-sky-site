# Framing rule — AI-assisted tooling (Hex notebooks, SQL, dashboards, scripts)

The problem: the dashboards, Hex notebooks, and scripts were built by
directing Claude Code, and the owner has working SQL knowledge but not a
foundational grasp of the other languages. They also genuinely shipped,
run in production, and helped projects succeed. The resume must not
overstate ("proficient in Python") or understate ("used dashboards").

## What is true, and therefore claimable
- Identified the operational need, specified the tool, and defined the
  metrics/logic it had to implement.
- Built it (AI-assisted), iterated it, debugged it against real data,
  deployed it, and maintained it.
- Others used it; it changed decisions or saved time.
- Working knowledge of SQL, gained on the job.

## Phrasing that says exactly that
- "Designed and built [tool] in Hex (SQL + AI-assisted Python) to ..." —
  names the tool, names the stack, names the assist.
- "Specified and shipped ...", "Built and maintained ...", "Developed with
  AI-assisted coding tools ..." — action verbs about delivery, not about
  language mastery.
- In the skills section, tier it: **SQL (working)** · **Hex, dashboards,
  data QA tooling** · **AI-assisted development (Claude Code): builds
  production internal tools** · do NOT list Python/JS as standalone skills.
- "Vibe coding" is fine in conversation; on the resume use "AI-assisted
  development" — it's the term hiring managers in this field recognize.

## Phrasing to avoid
- "Proficient in Python/JavaScript", "software engineer", "wrote a
  codebase", any claim about fundamentals.
- Hiding the assist entirely. In AI-data-ops roles, fluency at building
  with AI tools is itself the selling point; hiding it forfeits that and
  sets up an awkward interview.

## Interview-proof test
Every technical bullet should survive: "Walk me through how you built
that." The honest answer — "I defined the metrics and the logic, built it
with Claude Code, validated it against project data, and iterated when
the numbers looked wrong" — is a strong answer for these roles. Write the
bullet so that answer is what it implies.
