Hum Vowel Bars — Shape Prototype

Each Library hum note draws a bar at its pitch; the bar's shape is determined by the note's vowel (closed→open: ng · oo · uh · oh · ah). A sandbox for the Library track's hum bar.

Each vowel is a bar with its own width, height, and top-corner roundness (0 = square top, 1 = full dome) — currently oo is the most rounded. Roundness scales them all at once. The sides ripple with the live hum waveform (Ripple/Wave smooth). Live mode taps the real hum and reads the vowel from each note event; the manual buttons drop one bar per vowel for side-by-side comparison.
