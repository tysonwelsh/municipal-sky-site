Hum Vowel Bars — Shape Prototype

Each Library hum note draws a bar at its pitch; the bar's shape is determined by the note's vowel (closed→open: ng · oo · uh · oh · ah). A sandbox for the Library track's hum bar.

Each vowel has its own width, height, peak (+ pointed / − concave, edge to edge) and pointed (sharp vs smooth). Roundness applies to oo only (its rounded/domed top); every other bar has square corners. The sides ripple with the live hum waveform (Ripple/Wave smooth). Use Edit shape to pick a vowel and tune just that bar; Copy params dumps every vowel's values. Live mode taps the real hum; the manual buttons drop one bar per vowel.
