Harpsichord Strings — Ridgeline Prototype

One row per octave. Each harpsichord note plucks a vibrating string at its pitch. A sandbox for the Library track's bespoke visualization.
Style
idle
Notes: C–D–E♭–F–G–A–B♭ (the harpsichord's C-minor set), octaves 3–5. Higher strings vibrate faster. Live mode taps the real Library harpsichord; Demo plucks random notes; the buttons pluck specific notes.
