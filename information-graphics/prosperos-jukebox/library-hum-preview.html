Living Voice

~ hum, fully ranged ~

Every parameter is a min/max range. On each note (or each phrase, where appropriate), the engine picks a fresh value inside that range — so nothing is metronomic. Voice-character defaults sit at low values with small spread so the voice feels natural rather than artificial. The ▶ monitors on the left use the midpoint of each range, updating live as you drag handles.
