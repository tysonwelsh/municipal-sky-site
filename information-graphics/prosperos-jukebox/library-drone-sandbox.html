Goal: find drone settings that make Prospero's drone visibly modulate on the ridgeline without changing the essential musical character. Each control isolates one knob you could turn in the engine. Default values match the current engine (triangle waves, 180 Hz cutoff, no wobble, no beating).

The fastest-impact changes are usually Wobble Depth (1–5 Hz) and Beat Mix (with offset ~2–4 Hz). Both create continuous modulation that the FFT shows as visible peak movement. Raising the LP Cutoff (e.g., to 600–1000 Hz) exposes the partials' harmonic content; combined with a sawtooth wave mix you'll see multiple peaks per partial.
