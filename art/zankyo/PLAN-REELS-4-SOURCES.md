# ZANKYŌ reels, round 4 — the scouts: native sources in the non-English web

*Plan, 2026-09-14. Owner's answers, same day: media types 1–9 (10, audio, is a
later pass; 11, oral history, dropped — a lone face talking at length is
not a caught signal); one scout per locale; scouts on Opus. Launched
2026-09-14 from main while `zankyo-shapes` waits to merge.*

## 0. Why a source round before a video round

The pool is 208 reels from 81 countries, and it sounds like the whole
world — but it was fetched from two Anglophone hosts:

| host | reels |
|---|---|
| archive.org | 124 |
| youtube.com / youtu.be | 80 |
| bilibili.com | 2 |
| soundcloud.com | 1 |
| local file | 1 |

Rounds 2 and 3 scouted *videos*: eight beats searched the non-English web
with native terms, but when they found something they nearly always
fetched the YouTube or Internet Archive copy, because those are the hosts
the tools already read well. The material a country keeps on its own
archive portal, its own video host, its own fan sites — the material that
was never re-uploaded to YouTube — is still unreached. That is the deep-cut
tier. This round finds the *sites*; a later round (the ordinary
research → cut phases of PLAN-REELS-3 §5) picks the videos.

Definition of **native source**, the owner's: a website whose primary
holdings are in the locale's own language, run from inside the locale.
Excluded by rule: YouTube, the Internet Archive, and their mirrors.
Global hosts with a native centre of gravity count (Bilibili, Niconico,
VK, Aparat, Rutube, Dailymotion for France); English-language global hosts
(Vimeo) do not.

## 1. Where the vibe leaves us (unchanged)

A derelict station receiving the past. Idents, sign-offs, test cards,
clocks, weather, announcements, PSAs, newsreels, jingles, a face looking
into the camera. Beauty and strangeness; not punchlines. 1930s–1990s,
mostly ephemera, about one recognisable moment in ten. Everything ends up
as 4–12 s (or one 18–40 s) windows at 192×144 grayscale with mono
band-limited audio.

## 3. The preliminary swarm — scouts for SITES, not videos

### 3.1 What a scout delivers

One register row per candidate source, in a shared schema, plus a short
report. **No downloads, no video queues.** The only technical act allowed
is a single `yt-dlp -s` (simulate) or `-F` (list formats) against one
representative page per site, to learn whether the site is machine-readable
at all; the reels-3 etiquette (§2 of that plan) binds otherwise.

Register schema (`art/zankyo/broadcast/SOURCES.md`, one table per beat,
then merged):

| field | meaning |
|---|---|
| url | the site's entry point, plus one representative page |
| country / language(s) | as the owner's pool records them |
| type | §2 number |
| holdings | what it has, in one line: eras, volume, genres; the specific series or collections worth a later video scout |
| era fit | how much of it is 1930s–1990s |
| deep-cut score 1–5 | how unlikely this material is to be on YouTube or archive.org (5 = never re-uploaded) |
| access | public player / registration / geo-blocked / paywall / DRM, as found |
| readable | yt-dlp extractor exists (name) / generic reads it / HLS visible in the page / not readable — from the one probe |
| licence posture | what the site's terms say, as found; Tier A/B guess |
| etiquette | robots.txt, rate notes, anything the site asks |
| native terms | the search words that found it, so the video round can search inside it |
| why it fits | one line, in the broadcast-crew register (SHARED.md vibe) |

where a native source could replace a YouTube fetch, and writes the round

### 3.3 Phase 0 — the mechanical seed (one agent, before the scouts)

yt-dlp 2026.08.19 ships 1 752 extractors, and most native hosts worth
reading already have one (Aparat, Bilibili, Niconico, Naver, Kakao, VK,
Rutube, Smotrim, sibnet, Vbox7, Videa, Stream.cz, Sapo, Vidio, Zing, INA,
Rai, RTVE, RTP, NRK, SVT, DR, YLE, NPO, VRT, ERR, LRT, LSM, TVP, Česká
televize, ertflix, HRTi, Globo, Telewebion, NHK, TVer, CCTV, Youku …). A
seed agent walks the extractor list, buckets every extractor by country
and language from its domain, and hands each beat a starter list with the
extractor name beside it — so the `readable` column starts half filled and
the scouts spend their time on the sites yt-dlp does NOT know: archive
portals, fan sites, national libraries.

Second seed, same agent: the aggregators. Europeana, the European Film
Gateway, filmarchives-online.eu and Wikidata's "film archive" / "public
broadcaster" instances by country all point back to native hosts. The seed
agent lists them per beat; the scouts follow the pointers home.

### 3.4 How a scout searches

- In the language, in its script, with the terms the reels-3 beats found
  worked (試験放送 / クロージング, Sendeschluss / Testbild, заставки / уход
  с эфира, carta de ajuste / cierre de emisión, monoscopio / chiusura, 방송
  종료 / 시험방송, 收台 / 測試卡 …) plus the archive words (archivio, arquivo,
  архив, アーカイブ, 자료, 档案, arşiv, ארכיון, أرشيف).
- Reads the language's own Wikipedia for the national archive, the
  broadcaster's archive project, the film institute, and follows their
  external links.
- Checks each candidate against the pool's manifest (`src` column) so the
  register never lists a host the pool already reads.
- Records dead ends in the register's *rejected* table with the reason
  (login, geo, DRM, English-only, mirrors YouTube) so nobody re-scouts.

### 3.5 Gates

| phase | who | gate |
|---|---|---|
| S0 seed | seed agent | per-beat starter lists from the extractor walk and the aggregators; `SOURCES.md` scaffolded with the schema |
| S1 scout | 12 beats | 15–30 register rows each, every field filled, at least 10 rows on sites yt-dlp does not know, a top-5 with one line each on why it should be scouted for videos first, a rejected table |

Owner reviews the ranked register; the video round (research → cut, the
reels-3 shape) is planned from it.

### 3.6 Practicalities

- **Where:** documents only, so no worktree is needed; the crew works in a
  session scratchpad `reels4-scouts/` (briefs, per-beat reports) and the
  cartographer commits `art/zankyo/broadcast/SOURCES.md` alone. Nothing in
  this round touches the engine or the pool, so no VERSION bump.
- **Crew:** 12 scouts + the orchestrator as seed and cartographer (the S0
  extractor walk is a one-line dump handed to every scout), c11 `launch-agent` in the
  municipal-sky-site workspace, one pane each, suppressed under this
  surface as parent; scouts report completion by mailbox, flag only on
  operator-only questions (a site that needs a decision on legal posture).
- **Model:** Opus for every scout (owner's instruction); the cartographer
  is the orchestrating session.
- **Time:** S0 about 30 min; S1 one to two hours per scout, in parallel;
  S2 about an hour. A single evening.
- **Etiquette:** WebFetch only; robots and rate limits respected; no
  logins; one simulate probe per site; nothing downloaded; nothing
  mirrored.

## 4. What this round does not do

It does not pick videos, cut reels, or change what the station plays. It
does not resolve the round-3 leftovers (the ~200 African airchecks, the
Voice of Kenya broadcast, Italy deeper) — those are ROADMAP items for the
video round, and the africa and romance-west scouts should note where
those leftovers' native homes are.
