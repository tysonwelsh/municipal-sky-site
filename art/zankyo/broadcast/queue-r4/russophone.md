## Site notes — https://arhiiv.err.ee/

**How its search works (this is the important part).** The site is an Angular SPA and a plain fetch of any page returns the same empty shell — there is no server-rendered HTML to scrape, and the search route `/otsi?phrase=…` renders nothing without JavaScript. The search is a **POST**, and guessing the body returns HTTP 500 every time. The working call, captured off a real browser session, is:

```
POST https://arhiiv.err.ee/api/v1/search       Content-Type: application/json
{"queryParams":{"phrase":"<term>","type":"video","page":1,"limit":20,
 "timeRange":"all","timeRangeFrom":null,"timeRangeTo":null,
 "includeTranscription":false,"advancedParams":[]}}
```

Results come back under `activeList` with `videoCount` / `audioCount` / `photoCount`, and each hit carries `heading`, `date`, `lead` (the full synopsis) and `url` (the slug). `limit` up to 40 worked without complaint. **`includeTranscription: true` searches inside the spoken transcripts** — not used this round, and it is the obvious next lever: it would find the computer item buried inside a programme about something else.

**The item endpoint is the real prize.** `GET https://arhiiv.err.ee/api/v1/content/video/<slug>` needs no POST, no auth and no browser, and returns everything a cutter wants:
- `info.year`, `info.dateCombined` (first broadcast, in Estonian), `info.synopsis`, `info.seriesTitle`;
- `metadata.data[].data[]` with `Kestus` (duration), the MXF filename and the full credit list;
- **`description.data[]` — the archivist's shot list, each entry with `beginTime` in milliseconds.** This is what every `moments` column above is built from. Divide by 1000 for seconds. Some items have one undivided entry (short newsreel items usually do) — those are marked `timing: audition`.
- `media.src.hls` and `media.src.dash` (protocol-relative; prefix `https:`).

**How the player resolves.** yt-dlp's `ERRArhiivIE` extractor reads that same item endpoint and hands back HLS plus DASH from `vod.err.ee`. Probed with `-j --no-playlist`: formats appear as `hls-<bitrate>` and `dash-f1-a1-x3`. One wart worth knowing — **yt-dlp labels the audio track "Chamoru" (`language: "ch"`)** on these items, because ERR's manifests tag the stream `ch`. It is Estonian (or Russian); ignore the label and do not let a language filter drop the track.

**Rate limits and robots.** `robots.txt` disallows only named crawlers (Ahrefs, SemrushBot, MJ12bot, dotbot, PetalBot, GPTBot); ordinary agents are unrestricted, and there is a published sitemap index. No throttling, no captcha and no complaint across roughly 120 requests in one session, paced at 0.8–1.5 s. Nothing needs a login.

**The sitemap is a search engine in its own right.** `https://arhiiv.err.ee/sitemap/index.xml` fans out to video1–8, audio1–14 and image1–29. The eight video files together list **79,248 video URLs**, and ERR's slugs are transliterated titles (diacritics stripped: `põhiseadus` → `pohiseadus`). Downloading them once (~60 MB, done here) gives an offline title index that can be grepped instantly and without touching the site — how the first pass of this scout was run, before the search API was cracked. Keep it: it is the cheapest way to enumerate a series.

**Licence, as found.** No licence statement appears on item pages, in the item API, or in the site chrome; the metadata block names the distributor (`Levitaja = ETV`) and the credits, nothing more. `info.downloadUrl` was empty on every item checked. ERR is Estonia's public broadcaster and this is its own archive published for public viewing, but nothing on the page grants reuse. **Tier B, fair-use posture: ≤ 6 windows, never a whole song or scene, music windows ≤ 10 s.** That cap bites hardest on #1, #4, #8, #11 and #12, which are mostly music — plan them as short windows over the visuals, not as excerpts of the pieces. The register's note stands: this is a public-service archive that publishes for reuse, and it is worth *asking* ERR rather than assuming.

**What else is in there, beyond this round's theme.**
- **`AK filmikroonika 1958-1991` — 8,931 items.** Individually catalogued newsreel stories, most of them one to three minutes, each its own page with its own shot list. This is the deepest single seam on the beat and it is exhaustively indexed: any subject the pool ever wants (a factory, a funeral, a ribbon, a queue, a song festival) is in there under an Estonian keyword.
- **Full `AK` bulletins from the 1990s** (`ak-21-nov-95`, `ak-09-09-1994`, …) publish their **complete rundown as timecoded text in the synopsis** — `00:01:38 VÄLIS…`, `00:04:22 JUULILEPPED…`. A cutter can pick an item out of an hour-long tape without auditioning a second of it.
- **`Saadete algmaterjalid 16mm filmilt`** — raw, unedited 16 mm rushes from ETV programmes, 1961 onward. Untransmitted texture, which is rarer than finished programmes.
- **`Akadeemikud`** — 60+ long studio interviews with Estonian academicians, 1980–90: physicists, astronomers, cyberneticists. A standing supply of "the scientist explaining the machine".
- **Audio and photo tiers exist and are indexed the same way** (14 audio sitemaps, 29 image sitemaps) with the same API shape — `api/v1/content/audio/<slug>`. Eesti Raadio goes back to 1926. When the audio tier opens, this site is ready on day one.
- **Holes on the theme.** Searching found **no test card** (`testpilt`, `proovitabel`: zero), **no sign-off or closedown item**, and **no lottery draw**: `sportloto` returns prize competitions, `loterii` a village raffle, `loosimine` only Eurovision running-order draws. The station's own furniture is present only obliquely, through films *about* the station (#15, #16, #25, #26, #30). If the pool wants an Estonian test card or an ETV closedown, it is not published here and will need a different source.
