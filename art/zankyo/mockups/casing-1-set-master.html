Notes

  • One casing recipe. The scope, speaker, mode module, log and console now use the set's exact gradient, 9 px end-draft with the parting line down both walls, cream top arris, 11 px radius and tool skin. Only the grime moves from part to part. Every opening is lipped like the tube; every recess is the set's .zk-well.
  • One cap tool. PLAY/STOP, the name plates, preview buttons, mute slides and slider thumbs all use the set's two-tone cap gradient and shadow stack. Each console row is a small ledge (a well holding three stations), the way the set carries its rocker, 受信 and volume. An open row's name plate latches down like PLAY.
  • The cabinet is a moulding now: the same resin, one shade darker, with a coarser skin, its own parting line, louvres moulded through it, and grime and sun-yellowing in place of rust. The serial plate is debossed into it, and the screws everywhere became ejector-pin witnesses.
  • Colour had to give. Magenta is gone. Instrument kanji are cream print instead of red neon, the preview is a plastic push instead of a magenta dome, and the mute is a slide printed 入 / 切 instead of green/red paper. The console is much quieter. Rows now differ only by their legends, which suits the "one maker" goal but loses the old neon energy.
  • Changed on the set itself: the 受信 lens lights LIVE (warm white) instead of amber, because amber now means a reported value. Everything else on the set is untouched.
  • Not reachable from CSS: the scope canvas (zankyo-viz.js) still hard-codes cyan/red/magenta strokes. To finish the port it should draw in SCREEN green, with WARN for the kyū energy. The log tags rely on border style, so the colour-blind reading is unchanged or better.
