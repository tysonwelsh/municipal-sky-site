Mockup 7d · THE PAPERWORK — the manila evidence wrapper

The record is the item tag’s file: the same manila stock (--slip-paper family, --slip-ink, --slip-line), the same brass grommet, the same red elastic — except the elastic now runs item → folder instead of item → tag. A typed label is pasted on the tab; a string-and-button closure holds it shut and visibly unwinds as the folder opens (string 0.06–0.40s, cover swing 0.30–0.74s, sheets settling 0.58–0.94s — under a second, and fully skipped under prefers-reduced-motion).

Legible at once — the spec allowed either click-to-shuffle or a stagger wide enough to read everything; this mockup takes the second. The contents sit as three distinct papers: the inside cover (typed provenance block + the violet RECEIVED stamp, printed straight onto the manila), the PROMPT sheet (near-white, mono, verbatim, under a paperclip — it never changes when you flip), and the RUBRIC sheet (ruled paper, one row per axis in taxonomy order, the overall grade struck across the lower half as a big diagonal rubber stamp with the taxonomy’s own description typed beneath). Each sheet is offset and canted a fraction of a degree so its neighbours’ edges stay visible — folder contents, not a stack of cards.

Two synthetic overlays, per the build contract, and they exist only in this mockup — neither is in the filed record: (1) subway rat r1 carries a grafted grade_history entry (choice, 2026-07-27, “mock — for layout”) so supersession renders — the old stamp sits part-visible beneath the new one, offset and faded, the way restamped paperwork actually looks; (2) subway rat r3 has its color axis treated as skipped so — · NOT ASSESSED renders. Everything else — prompts, grades, dates, notes, model labels, axis and value labels, grade descriptions — is baked verbatim from taxonomy.json and the two entry.json files. No rubric string is hardcoded; unknown axes and object-form annotations ({value, note}) render generically.

Also in the file — the alternatives strip is worded ALSO IN THE FILE and drawn as further tabbed papers. Choosing one swaps the lifted SVG in place at the same scale and re-renders only the per-response papers; the PROMPT sheet is untouched. Hairball has a single response, so the strip is absent entirely (switch items above to see it collapse). Each response’s inline SVG has every id and url(#…) reference prefixed (o_, f_, s_, h_) so four artworks can share one page; no path was altered.

Mobile (≤768px) — the folder compresses: the sheet is the folder. The bottom sheet is cut from the same manila, its drag handle is the tab (typed label and grommet included), and the closure hangs at the tab’s right corner. Peek shows the tab, the model/process chips, the grade stamp and the file strip; full raises the sheet over the papers — prompt, rubric, inside cover, provenance — in an inner scroll region (overscroll-behavior:contain). Tapping the tab toggles the detents, and ?mock-state=peek|full drives them for screenshots; ?item=2026-07-27-hairball picks the item and ?rid=r3 picks the response (the same states the flip-through and the item switcher reach by hand).
