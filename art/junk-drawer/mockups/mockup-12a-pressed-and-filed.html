Design Notes · 12A Pressed & Filed

  • Three ruled registers. Two hairlines (rgba(74,53,18,0.28)) split the tag into name / filing grid / button bar. That is the whole layout story: every variant reads in the same three horizontal bands, so tags feel stamped from one die even when the content differs.
  • A real label/value grid. MODEL, FILED, GRADE share a fixed 3.4rem label column (2.9rem narrow); all values start on one left edge. The old tag ran "model · date" as an inline sentence — splitting the date onto its own FILED row costs one line but buys alignment, and the two-line name reserve means total height stays steady anyway. Labels are presentation, not new data.
  • Type scale, four steps, one rhythm. Name 0.7rem/700/0.07em; values 0.62rem; button text 0.55rem; labels 0.5rem caps at 0.18em tracking. Rows sit on a shared 1.5 line-height so the grid keeps a baseline beat. Narrow variant steps everything down one notch (0.62 / 0.56 / 0.5 / 0.46rem).
  • Name clamp unchanged in behavior. -webkit-line-clamp: 2 with min-height: 2.8em (2 × 1.4 line-height) — a short name reserves the same two lines a long one uses (tags 1 and 2). The one remaining growth is a wrapping model label (tag 2), which pushes the tag downward only — pick() measures the tag's height at runtime, as today.
  • Gauge kept verbatim, right-aligned on the GRADE row so its right edge lines up over the button bar's right edge. Verdict word sits by the label, meter flush right — the row reads label → word → measure. UNGRADED shows the dim verdict + empty bordered track per the shipped spec.
  • Buttons: one line, equal halves. The old two-line centered buttons are now a full-width bar: flex 1 each, 3px radius, faint cream fill and a 1px drop under the border so they read pressable against the manila. Download-only (tag 3) is the same bar with one button taking the full width — no layout special-case. White-space: nowrap holds each label to one line at both widths.
  • Material, all inline/CSS: a 140px feTurbulence data-URI at ~5% for paper grain, a 178deg sheen (light top edge, faint soot at the foot), inset 1px cream edge, and border-radius 0 7px 7px 0 — the clip-path polygon keeps the full right edge, so the radius survives it while the point stays sharp. Grommet is an 11px radial-gradient washer with a dark bore, ringed by 2px of paper so it reads seated, not printed.
  • Grommet stays left-edge, vertically centered — the seat/rope math in pick() and the Verlet elastic anchor there today; no reason to move it. The red stub in each stage is mockup-only scenery showing the attachment reads.
  • Integration watch-outs: (a) the tag is drawn with border + clip-path as shipped, so the border still vanishes along the pointed bevels — unchanged from production; (b) filter: two drop-shadows replaces the single one — keep the .is-dragging will-change promotion; (c) the paper-grain background-image joins background-color on the same element — no new DOM; (d) buttons remain <a> with cursor:pointer, everything else stays the grab surface; (e) date value keeps white-space:nowrap so ISO dates never split at hyphens; the model value still wraps (see tag 2 at 17rem).
