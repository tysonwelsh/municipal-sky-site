Mockup 7a · The Report Card — the full record, style A

PLAN-RECORD §3 A, revised per owner (2026-07-28): the visual theme stays; the wording doesn't. The register is still a letterpress-printed report card, roughly 1900s–1930s — manila-cream stock, a double hairline border with squared corners, faded blue-black form matter, paper grain and a fold crease — but every label describes what is actually depicted: MODEL (+ vendor), GENERATED (the response date), CREATED (the item's date) and PROCESS (the honest turn count — “one-shot (1 prompt)”). THE PROMPT is verbatim, always monospace, quoted as received; it is the item-level constant and it never changes when you flip responses. The ANNOTATIONS table prints one row per axis in taxonomy order — AXIS, VERDICT, NOTES — and closes with OVERALL GRADE as its footer row (heavier rule above). Removed for now (owner, 2026-07-28): the school-district masthead and its rule, the promotion line + curator's signature, the provenance notes paragraph, and all grade-history / marked-date / superseded rendering — freeing vertical room to bring the artwork and the alternatives onto the card itself (next revision).

The red pencil. Only the curator's own judgments are hand-inked: the axis VERDICTs and the OVERALL GRADE (large, double-underlined). Each mark takes its own rotation jitter and its own feTurbulence displacement filter (all with stitchTiles="stitch") so no two sit identically. Everything else on the card is printed form matter. Every rubric string — grade labels, ranks, descriptions, axis labels, value labels, model labels — renders from the baked taxonomy.json object. Nothing is hardcoded.

One synthetic overlay (no real entry has this state yet; disclosed here and never inside the card): subway-rat r3's color axis is treated as skipped, so the VERDICT cell renders the muted typed — · NOT ASSESSED. (The earlier mock grade-history graft is gone — supersession is no longer rendered at all.) Everything else — prompts, grades, annotations, dates, provenance notes, the artwork — is baked verbatim from items/2026-07-27-subway-rat/ and items/2026-07-27-hairball/.

Notes column. No response in the data carries an annotator note yet (annotations are bare value ids). Where a note exists the NOTES cell prints it; where it doesn't, the cell falls back to the taxonomy value's own description, set in printed italic rather than the hand — so the red pencil never claims a remark the curator didn't write. Add a note to an annotation and it appears in roman, in the same cell.

Flip-through. The strip is captioned OTHER MODELS, SAME PROMPT; choosing a model swaps the lifted SVG in place (same box, same scale) and re-renders every per-response field — the prompt block is untouched. Hairball has one response, so the strip is absent entirely (that's the state it's baked in for). Both entries' SVGs share this one page, so every id and every url(#…)/href reference is prefixed per response (o_, f_, s_, h_; strip thumbnails take …t_) exactly as the rating instrument does. The artwork paths are never altered.

Mobile (≤768px) — the PLAN-MOBILE §4 bottom sheet: lifted SVG in the top 45svh, the card as the sheet. Peek shows the title, the fill-in lines and the strip; full adds the prompt, the annotations table (with the OVERALL GRADE footer row) and the card foot, with an inner scroll region (overflow-y:auto; overscroll-behavior:contain). The detents are a CSS order reshuffle of the same blocks — one DOM, two readings. Tapping the handle toggles; the peek height is measured from the strip, not guessed. ?mock-state=peek and ?mock-state=full drive it (that's how the verification screenshots were taken).

Natural name — REPORT CARD (gate G7). The stage here is the simplified scrim of §4, not the production drawer: a warm radial backdrop with a vignette, the item lifted at ~55% with a long soft shadow. No blend-mode layers anywhere on the stage.
