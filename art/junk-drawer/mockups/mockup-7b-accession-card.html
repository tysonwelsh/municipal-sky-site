Mockup 7b · The Accession Card — PLAN-RECORD §3 B

THE REGISTRAR'S OBJECT CARD. Buff index stock with pale-blue feint rules and one red vertical margin rule; the form matter is letterpress-printed in tiny small caps with dotted fill-in rules, and every value is typed in Courier on the rules. ACCESSION NO. is promoted to the top line — this style's flourish. The overall grade is a red rubber stamp, canted a few degrees, with uneven ink (mockup-3's turbulence-displacement technique, re-registered from red pencil to rubber: edge displacement plus a second noise field eroding the ink so the strike is patchy). The taxonomy's own description for that grade is typed beside it; the graded date sits beneath.

THE FLIP — the verbatim prompt is not on the face of the card. It is typed on the reverse, under a printed VERBATIM PROMPT heading, where a cataloguer would actually put it. The dog-eared bottom-right corner and the typed OVER → are the affordance; clicking either turns the card in 3-D. The reverse carries the same stock mirrored — the red margin rule now runs down the right edge — and its own dog-ear at the bottom left turns it back. The prompt never changes when you switch responses; it belongs to the item, not the model. On mobile the flip works as-is in the full detent (the sheet's card turns in place); in the peek detent the dog-ear is hidden and turning over first expands the sheet — a card you can't read the back of isn't worth turning.

FLIP-THROUGH — the strip is captioned RELATED ACCESSIONS, SAME PROMPT and lists every response filed against this prompt, each with its model and its own grade. Choosing one swaps the lifted SVG in place at identical scale and re-types the card's per-response fields (MAKER, RECEIVED, METHOD, CONDITION, the grade stamp, REMARKS). The shown one is bracketed in red. Hairball has a single response, so the strip is absent entirely — switch items above to see the card close up around it.

TWO SYNTHETIC OVERLAYS, and only two — stated here because they are never disclosed inside the card itself. (1) The subway rat's first response carries a mock grade_history entry (choice, 2026-07-27) so supersession renders: the typewriter correction, the old grade struck through with a row of xxxx overtypes, the new stamp beside it. No real entry has been regraded yet. (2) The subway rat's third response is treated as though its color axis were skipped — the real entry grades it clean — so the muted typed — not assessed rendering is demonstrable. Everything else on this page is baked verbatim from items/2026-07-27-subway-rat/entry.json, items/2026-07-27-hairball/entry.json, their SVG files, and taxonomy.json (schema 1, version 5). Every grade label, rank, description, axis label, value label, value description, model label and vendor is resolved through the baked taxonomy object at render time — no rubric string is hardcoded, and an unknown axis or value still renders.

SVG HYGIENE — four artworks share this one page, so every id and every url(#…) / href="#…" reference is prefixed per response (o_ opus, f_ fable, s_ sonnet, h_ hairball; the strip's thumbnail of the same response is a second instance, o_t_ …), exactly as the rating instrument does. The artwork paths themselves are untouched. The page's only feTurbulence outside the stamps is the card's paper grain, and it carries stitchTiles="stitch". No full-stage blend-mode layers.

MOBILE & SCREENSHOT DRIVERS — at ≤768px the stage becomes the PLAN-MOBILE §4 bottom sheet: lifted SVG in the top 45svh, the card as a sheet at peek (accession no., object, maker, method, the grade stamp, the strip) expanding to full (adds condition, remarks, foot, dog-ear, inner scroll with overscroll-behavior: contain). Tapping the handle toggles the detents. The mockup honours ?mock-state=peek|full, ?mock-flip=1 and ?mock-item=hairball — which is how the verification screenshots drive it.

NOT SHOWN, DELIBERATELY — schema, rid, sizeClass/sizeScale, model_version. tags is empty on both items so no TAGS line prints; transcript is null on all four responses and the layout reserves no space for it. DOWNLOAD SVG ⤓ lives on the card foot and serves the byte-exact source as generated.

Natural name — ACCESSION RECORD (gate G7). The style and the name are separable: this card's look can win while its name loses.
